## 使用方法（约 5 分钟）

1. 用 Excel 打开 `02-additional-boq.csv`。  
2. 删除**不属于**额外范围的行。  
3. 填写**工程量**。仅在采购要求带价 BoQ 时填写**单价**和**合价**；否则单价留空，只发工程量及工作内容。  
4. 打开 `03-drawing-register.csv`。只保留实际已有的图纸，并附上对应 PDF/DWG。  
5. 复制 `01-email-reply.md` 中的邮件，附上 Excel 版 BoQ 和图纸后发送。
